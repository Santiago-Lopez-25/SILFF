# Hi! Thanks for contribute

I made this project only for learning reasons; but if you see it insteresting, you can contribute!

## Steps
1. fork this repository, this will create a copy in your account
2. clone it with `$ git clone URL`, changing URL with the URL of the repo in your profile
3. make a new branch with `$ git checkout -b NAME`, changing NAME with some name you like
4. start making changes. add, remove and/or change files. when you feel ready, make a final commit
5. then, push your changes to the branch: `$ git push origin name_of_your_branch`
6. then go to github and create a new pull request with a good description
7. You make a contribution, congratulaitons!

## Code style
the code style is important to understand the code. please, follow these guidelines if you contribute:
* use a 4 space indentation
* add some good readable doc comments
* if you used prints or similar for debugging, just comment them, don't delete them
